## ✨ Features

- 🍏 **iOS 17/18 Visual Aesthetic**: Authentic Apple keyboard geometry, key aspect ratio, colors, and key pop-up magnification preview.
- 🎚️ **Slider Suara & Getaran (Baru)**: Atur kekuatan getar (dari 5 ms hingga 100 ms) dan volume suara ketikan (dari 0% hingga 100%) langsung menggunakan slider halus di menu pengaturan dengan tes getar & audio real-time.
- 📳 **Getaran Haptik Merata di Semua Tuts**: Pulsa haptic hardware OneShot khusus yang mengatasi inersia motor getar HP, memastikan setiap ketukan tuts huruf, angka, spasi, dan simbol terasa mantap.
- 💬 **Kursor Interaktif Mode Terjemahan**: Kursor biru khas iOS (`│`) yang dapat disentuh dan digeser langsung ke tengah kalimat untuk mengedit teks terjemahan secara fleksibel.
- 🚪 **Auto-Close Mode Terjemahan**: Panel terjemahan otomatis tertutup begitu kalimat selesai dikirim ke chat atau saat berpindah aplikasi.
- ⚡ **Nulis Otomatis (Next-Word Prediction & 3.000+ Kosakata)**: Ketik satu kata dan bilah saran langsung memunculkan prediksi kata berikutnya secara berantai (`saya` ➔ `mau`/`bisa`/`sudah` ➔ `makan`/`pergi`), memungkinkan mengetik kalimat lengkap hanya dengan tap saran kata.
- ↵ **Tombol Return Fleksibel Adaptif**: Berubah otomatis menjadi ikon `🔍` pada kolom pencarian web, teks `Buka` pada URL browser, dan panah `↵` (baris baru `\n`) pada WhatsApp & kolom chat multiline.
- 🎨 **Adaptive Themes**: iOS Light, iOS Dark, OLED Black, dan Automatic (System Theme sync).
- 😀 **Full Apple Emoji Board**: Categorized emoji drawer with fast scrolling and intuitive category picker.
- 🌐 **In-Keyboard Live Translation**: Instant translation while typing powered by Google Translate API (supports ID ⇄ EN, Arabic, Japanese, Korean, Spanish, etc.).
- ✍️ **Smart Typo Buster & Suggestion Bar**: Offline dictionary and Levenshtein distance algorithm for accurate auto-correction.
- 📦 **Downloadable Offline Language Packs**: Download additional offline dictionaries directly from within the app.
- 🔊 **Tock Audio & Taptic Feedback**: Authentic Apple iOS keyboard click sound and crisp haptic vibration feedback.
- 📋 **Integrated Clipboard Manager**: Access and paste recent copy-paste history straight from the keyboard toolbar.
- ⚙️ **Cupertino Settings Hub**: Apple-style inset grouped settings interface with real-time test pad and simple 2-step system activation.

## 🛠️ Architecture & Tech Stack

- **Platform**: Android Native IME (`android.inputmethodservice.InputMethodService`)
- **Language**: Kotlin 1.9.24
- **Build System**: Gradle 8.7 + Android Gradle Plugin 8.4.1
- **Target SDK**: Android 14 (API 34), Minimum SDK: Android 7.0 (API 24)
- **Zero-Latency IME**: Native rendering with 0ms typing latency and lightweight footprint (~15MB RAM).

## 🚀 Setup & Activation

1. Unduh dan install **`iOSKeyboard.apk`** dari link rilis di atas.
2. Buka aplikasi **iOS Keyboard Settings**.
3. Ketuk **"1. Aktifkan di Pengaturan Sistem"** dan aktifkan switch **MaoneArt iOS Keyboard**.
4. Ketuk **"2. Pilih sebagai Keyboard Utama"** dan pilih **MaoneArt iOS Keyboard**.
5. Selesai! Rasakan sensasi mengetik ala iPhone di Android Anda.
